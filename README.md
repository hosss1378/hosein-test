# Hosein Test Project
This project contains a web-based showcase featuring 3D models, videos, and interactive targets.

## Project Structure
- `index.html`: Main entrance page.
- `admin.html`: Admin control panel.
- `models/`: 3D models in GLB format.
- `videos/`: Product demonstration videos.
- `targets/`: Image targets and configuration files.
- `serve.ps1`: Script to serve the project locally.
